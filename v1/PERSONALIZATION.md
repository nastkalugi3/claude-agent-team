# Персонализация Claude (claude.ai и приложение)

Команда агентов из этого архива работает в **Claude Code**. В обычном чате Claude
настраивается отдельно, по пунктам ниже.

## 1. Личные предпочтения (Настройки → Профиль)
Вставь в поле с предпочтениями и поправь под себя:

```
Отвечай по-русски. [Кто ты: учёба, работа, бэкграунд — 1–2 строки.]
Стиль: коротко, по делу, без воды. Работай самостоятельно, не задавай лишних
вопросов, если можно принять разумное решение. Честно говори, что не получилось
или в чём ты не уверен. Для актуальных фактов (версии, цены, вакансии, новости)
ищи в интернете и давай источники. Код — рабочий, проверенный запуском.
Для сложных задач сначала короткий план, потом результат.
```

## 2. Функции, которые стоит включить
- **Память**: «Генерировать память из чатов» и поиск по прошлым чатам.
- **Веб-поиск**.
- **Коннекторы**: Google Drive, Gmail, Google Calendar и GitHub.
- **Компьютер**: через приложение Claude Desktop — доступ к папкам, браузер, управление приложениями.

## 3. Проекты как «отделы» в чате
Создай отдельный Project на каждое направление, в которое возвращаешься постоянно.
В инструкцию проекта вставь текст роли из соответствующего файла `.claude/agents/*.md`
(всё, что ниже строки `---`). Файлы с материалами (программа курса, датасеты,
учебник) загрузи в проект.

Предлагаемые проекты:
- **DS / портфолио** — data-scientist + data-analyst + developer
- **Школа, 10 класс** — teacher
- **Карьера и стратегия** — strategist (+ вакансии через веб-поиск)
- **Тексты и бренд** — copywriter + editor
- **Мышление** — philosopher + scientist

## 4. Плагины и навыки
Официальные плагины Anthropic для разных профессий (engineering, data, design,
marketing, product-management, operations, finance, HR, sales и др.):
github.com/anthropics/knowledge-work-plugins

Часть из них уже подключена у тебя. Для тебя главные:
- **data** — анализ, SQL, визуализация, дашборды, валидация анализа
- **engineering** — code review, отладка, архитектура, тесты, документация
- **design** — критика дизайна, UX-тексты, дизайн-система, доступность
- **marketing** — контент, посты, рассылки, SEO
- **product-management** — брейнсторм, спецификации, планирование

Свои повторяющиеся процессы можно упаковать в навык. Попроси: «сделай навык из этого
процесса», например «проверка ноутбука перед сдачей в Нетологию» или «план урока по
моему шаблону».
